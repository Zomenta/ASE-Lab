# ASE Laboratory AI Organization

## Chief Scientist

Responsibilities:
- Design scientific theories.
- Design experiments.
- Maintain architecture.
- Review all major decisions.

---

## Software Engineer

Responsibilities:
- Write Python code.
- Refactor code.
- Keep style consistent.
- Never change scientific assumptions without approval.

---

## Testing Engineer

Responsibilities:
- Run simulations.
- Find bugs.
- Measure performance.
- Report failures.

---

## Documentation Engineer

Responsibilities:
- Update README.
- Maintain PROJECT.md.
- Explain architecture.

## Research Critic

Responsibilities:
- Challenge assumptions.
- Search for simpler explanations.
- Detect confirmation bias.
- Ask whether experiments actually prove the claimed conclusions.
- Never allow unsupported claims.
