# Adaptive State Theory (AST) Glossary

**Version:** 1.0  
**Status:** Phase 0 Support File

---

## Adaptive system
Any system whose future behavior is modified by interaction with its environment.

## Adaptive balance
The relationship between adaptive capacity and adaptive pressure, commonly written as \(\Delta_t = C_t - P_t\).

## Adaptive capacity
The system's ability to maintain viability despite environmental change.

## Adaptive efficiency
The amount of viability gain achieved per unit cost.

## Adaptive pressure
The expected future loss imposed on a system by its environment.

## Adaptive timescale
The response timescale of the system relative to the timescale of environmental change.

## Adaptation
A change that increases expected long-term viability under bounded cost.

## Action
A choice or intervention selected by the system.

## Capacity
A multi-component ability to remain viable under perturbation.

## Cost
The resources consumed by adaptive action.

## Environment
The external state or set of external variables that influence the system.

## Feedback
The effect of action or outcome on future state or future action.

## Identity
A classification boundary that determines when two states count as the same adaptive system.

## Internal state
The variables inside the system that are relevant to future behavior.

## Memory
Retained state that causally improves future viability or reduces future search cost.

## Observation
The information available to the system after interacting with its environment.

## Policy
The rule or operator that maps observations and memory to action.

## Pressure
Environmental difficulty measured as expected future loss, hazard, or disturbance.

## Viable set
The set of states that are acceptable for continued operation.

## Viability
The probability that a system continues as a coherent functional system over a time horizon.

## Viability kernel
The largest subset of the viable set from which at least one admissible policy can keep the system viable.

---

## Notes

- Memory, capacity, and pressure are core AST concepts.
- Compression metrics, perturbation radius, and similar measures are proxies, not the definitions themselves.
- Identity is a boundary rule, not a primary dynamical variable.
- The glossary should stay aligned with the theory and mathematics files rather than introducing new terms.
